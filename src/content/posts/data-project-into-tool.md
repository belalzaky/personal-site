A few weeks ago, my FAERS project was a folder of Python scripts. You ran one, it printed a chart, and it stopped. Useful for me, useless to anyone else — you had to have my laptop and know how to run Python to see anything.

This week I turned it into something you can actually click: type any drug, and it shows you that drug's most-reported adverse reactions, how its report count moved year over year, and the age/sex breakdown of who got reported. It's live, it's a link, and you don't need to install anything.

I expected the building to be the hard part. It wasn't. Here's what actually caught me out.
